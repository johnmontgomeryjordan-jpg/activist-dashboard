What this is

An early-warning system that scans U.S. public companies for signs of activist-investor vulnerability before an activist surfaces — so FGS can reach out proactively. It runs entirely on free, public data and refreshes itself automatically.

How vulnerability is scored

Every company is scored on a rolling 90-day window. Each signal adds points; a company is flagged once it reaches the threshold (currently 3). The highest scorers become the “Companies to Pitch” shortlist.

Layoff / restructuring announcement (8-K)1SEC EDGAR
Negative activist / restructuring headline1News API

Reading the score: 6–7 high 4–5 elevated 3 watch — a 7 means multiple distress signals stacked in 90 days (e.g. a CEO exit and an earnings miss and an impairment).

Where the data comes from

  • SEC EDGAR — official filings (8-K, 10-K, 10-Q) for the full S&P 1500. We read each filing's event codes and classify the distress signals above. This is the core, most reliable signal.
  • Financial news API — headlines filtered to activist / distress topics (CEO changes, activist stakes, guidance cuts, write-downs). We show the headline, outlet, date and a link out — never the article text.

How often it updates

  • Every 30 minutes — news headlines and EDGAR filings refresh, and scores recompute.
  • Daily at 4:00 PM ET — an email digest of the day's top headlines and top companies goes to all subscribers.

How it's built

A Python (FastAPI) backend pulls the data, runs the scoring, and serves this page; data is stored in a lightweight database; the whole thing is deployed on a hosted web service with a shareable URL. No paid data feeds are used.

On the roadmap (paid-data version)

Some signals need proprietary or licensed market data and are intentionally left out of this proof-of-concept. They’re natural next additions if FGS wants them:

  • Total-shareholder-return underperformance (1- / 3-year vs. peers) and a market-cap filter.
  • Valuation signals (low price-to-book, conglomerate / sum-of-the-parts discount).
  • SG&A vs. named proxy peers, M&A track record, CEO pay vs. performance, full peer benchmarking.

This is a proof-of-concept demo. Signal classification is a strong first pass but will occasionally mis-tag a filing, so the shortlist is a lead-generation starting point for a human to review — not a final determination.
